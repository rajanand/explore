A step-by-step walkthrough

What actually happens
inside a transformer?

We'll follow one sentence — the same one you can't parse without context — through every stage of the pipeline: from raw text, to numbers, to a model that knows exactly which word "it" refers to.

"The trophy didn't fit in the suitcase because it was too big."

Scroll down, or jump to any stage on the left. Step 4 is interactive — try flipping "big" to "small."

Step 01

Tokenization

The model can't read words — it reads tokens, small chunks of text (often whole words, sometimes word-pieces). The first thing that happens to any input is splitting it apart.

13 tokens, in order. Punctuation and word-endings can become their own tokens too.

Order is preserved for now — but notice that at this stage, tokens are just a list. Nothing here tells the model that "it" relates to "trophy." That comes later.

Step 02

Embeddings

Each token is converted into a vector — a list of numbers — that captures something about its meaning. Similar words end up with similar vectors.

Real models use hundreds or thousands of numbers per token. The vectors above are shortened for readability — but the idea holds: "trophy" and "suitcase" both being physical objects would already sit closer together in this space than either does to "because."

Step 03

Positional encoding

Here's the catch from processing everything in parallel: the model no longer reads left-to-right, so it has no built-in sense of order. A pattern added to each token's vector encodes where it sits in the sentence.

This is the direct fix for the tradeoff we made by dropping RNN-style sequential reading: we gained parallelism, so we have to explicitly re-inject position instead of getting it for free.

Step 04 — interactive

Self-attention

Now the key move: every token looks at every other token and asks, "how relevant are you to me?" Try it below — flip the ending of the sentence and watch where "it" points.

thick, bright arc = high attention weight from "it"    faint arc = low weight

With "big," the thing that didn't fit is the trophy — so "it" attends strongly to trophy and barely to suitcase.

Same sentence structure, same word positions — but attention is computed from meaning, not distance. That's why swapping one word can flip the connection entirely.

Step 05

Multi-head attention

One attention pattern only captures one kind of relationship. So transformers run several attention "heads" in parallel, each free to specialize in something different.

Head A · local grammar

Head B · coreference

Head C · negation scope

Head A links neighboring words like "the" and "trophy." Head B is the one doing the work we saw in Step 04, tracing "it" back to "trophy." Head C tracks how "didn't" reaches forward to negate "fit." All of this happens at once, then gets combined.

Step 06

Feed-forward network

After attention mixes information between tokens, each token is passed through the same small neural network on its own — refining what it now knows, independently of its neighbors.

token: "it" + context from attention
→
feed-forward network
→
refined vector for "it"

Think of attention as "gathering information from the room," and the feed-forward step as "sitting down alone to think it over." Every token gets this same private processing step.

Step 07

Stacking layers

One round of attention + feed-forward is called a layer, or block. Real models stack dozens of these, each one refining the representation further.

Layer 1 — attention → feed-forwardcoarse patterns
Layer 2 — attention → feed-forwardcombines Layer 1's output
Layer 3 — attention → feed-forwardincreasingly abstract
↻ repeated N times — small models: ~12 layers · large models: 90+

Early layers tend to pick up on grammar and local structure. Later layers build more abstract understanding — tone, intent, long-range facts — all built on top of what earlier layers already resolved.

Step 08

Predicting the next word

After the final layer, the model turns its representation of the sequence so far into a probability for every possible next token — then picks one.

"The cat sat on the ___"

This is the step we started with, back at the very beginning: next-token prediction. Everything before it — tokenizing, embedding, positional encoding, attention, feed-forward, stacked dozens of times — exists to make this one probability distribution as informed as possible.
